# ⚽ BR-K-Fut API

Uma API simples e rápida para consultar resultados do Campeonato Brasileiro de **2003 até 2024**.

Este projeto expõe dados históricos do Brasileirão através de endpoints REST, permitindo buscar:

- Jogos por rodada  
- Jogos de um time específico  
- Placar, mandante, visitante e outras informações da partida
